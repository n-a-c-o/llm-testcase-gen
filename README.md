# LLM Test Case Generator

A tool for generating test cases from user stories using fine-tuned language models.

## Features

- Convert user stories into test cases
- Support for Japanese language input and output
- Fine-tuned on Gemma 2B model

## Repository Structure

- `frontend/`: React frontend application
- `backend/`: Python backend API

## Development

See the README files in the frontend and backend directories for specific setup instructions.
